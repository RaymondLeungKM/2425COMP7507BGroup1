Group 1 of COMP7507 Visualization &amp; Visual Analytics Course Project (2024-25 Summer Semester)

## How to Access the Visualization

### 🖥️ Local Access

Download the **On the Right Track\_.twbx** file from this repository and open it locally on your PC using Tableau Desktop or Tableau Reader.

### 🌐 Online Access

You can access the visualization in two ways:

- Use the embedded dashboard on our website: [View Website](https://raymondleungkm.github.io/2425COMP7507BGroup1/)
- Visit the Tableau Public site directly: [View on Tableau Public](https://public.tableau.com/app/profile/isaac.mak/viz/OntheRightTrack/CoverPage)
